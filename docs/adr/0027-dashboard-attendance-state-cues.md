# Attendance state on the employee dashboard carries a redundant cue, and its type and motion follow pinned values

An interface audit of the employee dashboard found the attendance tiles carrying meaning in colour alone (a late arrival turns the time red with no other cue), three text pairs measuring below the 4.5:1 they need, motion that the project's reduced-motion block does not cover, two custom overlays that neither take focus nor close on Escape, no `<main>` landmark or skip link, changing figures without tabular digits, type as small as 9px, and truncated cells whose full value only a mouse can reach. We pin one interface contract for this surface: every state carries a second cue (icon, chip or text), every rendered text pair meets its measured ratio, motion runs only behind the existing `prefers-reduced-motion` block, overlays use native `<dialog>` semantics, the page exposes `<main>` with a skip link, changing figures use tabular digits, the type floor is 12px, and truncation offers a keyboard-reachable way back.

Considered: keeping the compact 9–11px density. Rejected — the measured pairs at those sizes fail 4.5:1 (`text-gray-400` on white is 2.54:1, `text-red-500` on the card tint is 3.59:1, white at 80% on the reminder gradient is 2.28:1), so the density is not a style choice but an accessibility failure. Keeping hand-rolled overlays was rejected for the same reason: focus containment, Escape and focus return are what the platform gives away.

Consequences: the tile grid grows visibly where 9px and 10px type becomes 12px, and the punch-out card's icon now keys on the logout value instead of a field nothing writes. The audit's measured pairs become the pinned values for this surface — 2.54, 2.28, 3.59, 3.76, 2.94 and 2.96 — so a future restyle is measured against them rather than by eye. The stated contract covers the employee dashboard and the project page's employee workspace; the reports and admin surfaces keep their own density until a similar audit measures them.
